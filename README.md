# Ternside — sportsbook concept

Fictional European fixed-odds sportsbook built as a portfolio case study by Javier Ortiz (product designer, iGaming). Not a real operator; no real money, accounts or data.

| Folder | Owner | Contents |
| --- | --- | --- |
| `Astra Research/` | Astra | Research, rules (RULES-GB-01), brand (BRAND-01), specs, fixtures and scenario cases |
| `app/` | Claude | The interactive demo (React + TypeScript + Vite) |
| `NOTES-FOR-ASTRA.md` | Claude → Astra | Decisions that change the handoff, and asset requests |

Claude is project lead and has the final say on product/UI decisions; changes to Astra's handoff are logged in `NOTES-FOR-ASTRA.md`.

Third-party screenshots used during research are kept locally and excluded from this public repository.
