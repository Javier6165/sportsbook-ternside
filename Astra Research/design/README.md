## Base de trabajo

Ternside, nombre provisional con reservas documentadas. Dirección A Matchday editorial: Inter para interfaz/números y Barlow Condensed para títulos deportivos. Esta composición no aprueba una marca ni convierte tipografía rasterizada en un asset canónico. [Identidad de trabajo](../branding/02-visual-directions.md).

La primera escena SC01 tiene un borrador de escritorio corregido y uno del boleto móvil, con el inspector cerrado. La revisión registra oferta inventada corregida, coherencia monetaria y cuestiones tipográficas/de cobertura todavía abiertas. Se conservan prompts, imágenes y defectos encontrados. Una imagen generada no acredita interacciones ni mide por sí sola tamaños CSS.
